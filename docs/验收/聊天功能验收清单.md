# NODO 聊天功能验收清单

使用项目的开发库和本地角色账号，双账号核对时用两个独立浏览器会话。用虚构的消息、图片和文件。临时改过的参数和个人设置，在验收后恢复。

## T1 人和群

- [ ] 管理员进入「讨论」后看到未读列表，页面没有自动打开某条会话。
- [ ] 「+ 聊天」中每人有头像、姓名和角色。多角色用顿号，无角色显示「未分配角色」。列表没有邮箱、手机号和 NODO 助手，也不列停用、门户或外部用户。
- [ ] 搜索「销售」能找到销售专员。筛选「采购」只列采购角色。姓名或角色搜索能与筛选同时生效。
- [ ] 选择销售专员发起私聊。聊天顶部显示姓名、角色和在线、离开或离线。
- [ ] 选两名以上同事创建群聊。核对默认名与成员角色，随后改名、加人和退出。

## T2 频道

- [ ] 全新库中有「全员通知」「销售报价」「生产协调」。检查三个频道的自动订阅组，以及系统管理员可见的「管理员」频道。
- [ ] 「全员通知」的新装频道没有上游欢迎语。普通员工在公告频道看到「本频道仅管理员可发言」，没有输入框，仍可加表情回应。
- [ ] 普通员工发消息接口被中文提示拒绝，审批负责人和系统管理员能正常发言。
- [ ] 普通员工没有「新建频道」入口，通过接口新建也被拒绝。管理员可建频道。普通员工仍可发起私聊和群聊。
- [ ] 为一名账号增加「生产」角色，确认自动加入「生产协调」。撤除角色时，原生成员机制可能保留已有成员，应在权限复核时检查。
- [ ] 频道顶部显示名称、成员数和说明，限制发言的频道有「公告」标记。空状态、浏览、加入和退出入口采用中文。

## T3 单据联动

- [ ] 在聊天中引用 S00001。卡片显示单号、客户、金额、现有状态，点卡片可打开报价单。再次打开会话时可见最新单据状态。
- [ ] 无单据权限的车间操作工查看同一条消息时看不到卡片，页面正常。
- [ ] 从 S00001 的「发到聊天」选择有读取权限的同事并填附言。对方不刷新就看到消息和卡片。发送人可从「去看看」打开会话。
- [ ] 能向有发言权的群聊和频道分享。只读公告频道无权发送。
- [ ] 无销售模块的新库能单独安装并运行 `nodo_base`，讨论可正常使用。

## T4 消息能力

- [ ] 在默认时限内撤回本人消息。对方不刷新看到撤回占位语，附件原文件无法访问。
- [ ] 管理员删除他人消息后显示管理员删除占位语。普通员工无法撤回别人的消息。
- [ ] 时限内编辑后显示「已编辑」。临时缩短 `nodo.discuss.recall_seconds`，验证超时后菜单无撤回和编辑，直接调用也被中文拒绝。恢复 120 秒。
- [ ] 私聊只在自己最后一条可见消息下显示「未读」或「已读」。对方打开会话后，状态免刷新更新。群聊和频道保留未读分隔线。
- [ ] 选文件、拖拽和 Ctrl+V 贴图都能发送。图片有缩略图且可放大，文件有名称、大小和下载入口。
- [ ] 选择超过 50 MB 的文件时立即提示上限。上传有进度，可以取消。
- [ ] Enter 发送，Shift + Enter 换行。用中文输入法选字时按 Enter 没有发出消息。输入 @ 显示会话成员姓名和角色。
- [ ] 核对回复、表情回应、置顶、复制、编辑、撤回等菜单文案。语音、通话、转发、书签和投票入口隐藏。

## T5 通知和上线前提

- [ ] 销售专员给停在其他应用的管理员连续发两条消息。顶部角标和页签按消息条数增加，讨论窄栏数字对应，右下角可点提示进入会话，读完后标题恢复。
- [ ] 允许站点通知并开启账号的桌面通知。把接收端浏览器切到后台，检查桌面通知的标题、摘要、NODO 图标及点击跳转。前台已打开当前会话时收件安静。
- [ ] 从会话设置开启免打扰，普通消息及 @ 提及都不弹提示，未读继续累计。核对后关闭免打扰。
- [ ] 在「我的首选项」关闭提示音，收件无声音。关闭桌面通知后仍能看到页面提醒和未读。重新登录或换独立浏览器后核对两项设置。
- [ ] 关闭「打开通知」提示后重新登录，提示不再出现。使用未关闭提示的账号拒绝站点权限后，页面说明如何重新允许，点击提示不再请求授权。
- [ ] 用 [部署前提](../聊天部署前提.md) 核对内网试点上的 HTTPS、WebSocket 和关页推送。以实际部署结果填验收，不用回环地址的结论代替。

- [ ] `scripts/nodo.ps1 test nodo_base` 和 `scripts/nodo.ps1 test nodo_base_sale` 通过。自动化覆盖 Store 角色可见性、频道发言与创建权限、单据卡片读取和分享权限、消息时限、附件大小、通知设置和免打扰。
- [ ] 验收目录中有本轮实现的截图，文件名前缀依次为 `20-聊天-`、`21-频道-`、`22-单据联动-`、`23-消息-`、`24-通知-`。
