# 66 · 附件选型与图集

2026-11-21 更新本机开发库。截图取自一次性验收库的技术账号。独立库使用七份现有附件网格，AE-202 复用同参数的双门柜网格。

## 实测

| 项目 | 结果 |
| --- | --- |
| 右侧选型 | 打开 BOM 第一行时，柜体画布大小、位置及相机取景保持一致。用名称按钮先选左门板，再直接点击三维右门板，右栏和轮廓同步。 |
| 型号与安装面 | 防尘罩必须先选安装面。三维点顶板后显示「板面已选」。应用后，该行草稿同时得到防尘罩型号和顶板。 |
| 隐藏板面 | 柜门关闭时，从侧栏选安装板，实际板面用虚线标出。 |
| 定位草稿 | 同型号、同版本、同安装面保留横向 37.5 mm、纵向 −16 mm、转角 90°。切换防尘罩和顶板后取消也保留原值。应用到不同板面时清除旧偏移并提示重新核对位置。 |
| 可用性与权限 | AE-SQ35 在双门柜上标记「柜型不符」，待工程核对的角码可查看依据，两项均禁用应用。其他公司的会话读取该公司的附件缩略图返回 404。 |
| 装配边界 | 选型过程未发起保存、柜体预览或装配预览请求。前后回读的设计参数和编辑号一致。「装配预览」继续作为计算入口。 |
| 附件图集 | 两种尺寸均读到七张 320 × 216 的真实网格缩略图，源网格摘要前后一致。图集无三维画布，打开详情只创建一张。返回保持滚动位置、搜索词、分类和状态。 |
