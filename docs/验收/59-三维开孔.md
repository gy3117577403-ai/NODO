# 技术工作台三维开孔

2026-11-20 在本机开发库 `nodo_dev` 使用技术岗位账号验收。通过顶栏「三维开孔」直接在三维模型上点选加工面、拖动孔中心和确认。普通「三维」点选留在模型中，用顶栏「二维」进入平面编辑。三维使用京能 0.57.3 固定版本的视口和孔位控制器，实际切除和出图由现有 CAD 计算进程完成。

本页记录当时的样例数据。当前开发库的基础柜和模型切换规则见[第 60 项验收](60-基础柜与开孔联动.md)。

| 样例 | 核对内容 |
| --- | --- |
| AE-101 单门 | 实测三维点选、拖到 U156/V147 mm、1 mm 吸附、一次撤销和重做、正对板面和恢复整柜视角。待确认时保存和出图均被拦截，即使已经切到另一面。确认 Ø22 mm 草稿后继续落孔，取消新孔，点已有 H2 修改，再切到二维读回相同坐标。草稿验收前后的设计记录与批次一致。 |
| AE-202 双门 | 以合门视角点右门板，界面 U187.71/V463.47 mm，独立投影 U187.708/V463.467 mm。为保留原样例，以同样的宽 1020、高 720、深 320 mm 另建 AE-306 验证开门定位和实际出图。 |
| AE-303 V02 | 从版本归档读取门板轮廓。同一个 21.2 × 21.2 mm 原孔在三维点选时显示来源，在 U362.5/V167 mm 输入同样的矩形也无法确认。验收前后设计记录与出图批次一致。 |

## AE-306 V01 实际出图

打开双门后在右门实体上点选，读到 U144.39/V169.11 mm，与独立投影在 0.15 mm 验收阈值内。随后把孔 H1 精确设为 U135.25/V155.75 mm，孔宽 24 mm、孔高 14 mm。合门后坐标一致，保存预览，再从页面发起一键出图。下载同一批次的四份文件后重新读取。

| 文件 | 回读结果 |
| --- | --- |
| 整柜 STEP | 在右门板厚三个深度测到贯穿，孔边外侧保留板材。左门对应位置仍为实体。 |
| 右门板切割 DXF | 毫米单位，切割层轮廓闭合。矩形孔四条边各出现一次。 |
| 右门板展开 DWG | 通过 ODA 转回 DXF 后，`CUT` 图层与同批独立切割 DXF 的图元一致。回读日志有字体表偏移提示，校验程序完成图元和坐标检查。 |
| 孔位表 CSV | 一个新孔，面为 `door_right`。板面 U135.25/V155.75 mm，对应展开 X148.07/Y167.35 mm，装配坐标 X882.25/Y0/Z158.75 mm。 |

样件版本界面显示「待工艺校核」。本次使用开发库中的三个样例和一套新出的样件工程文件。

## 复验命令

使用本机已安装的 Playwright 和技术岗位开发库会话。`--deliver` 写入独立样件 AE-306，重复运行复用相同交接样件和相同参数的图纸批次。

```powershell
.\scripts\nodo.ps1 update nodo_draw
node scripts/draw/verify_3d_holes.cjs
node scripts/draw/verify_selection.cjs --pick-only
node scripts/draw/verify_workbench_layout.cjs '.nodo-draw/output/playwright/drill-regression' hole-editing
node scripts/draw/verify_3d_holes.cjs --deliver
uv tool run --offline --no-config --managed-python --python 3.13 --from cadgen==0.7.26 python -X utf8 scripts/draw/verify_drill_delivery.py '.nodo-draw/output/playwright/drilling'
```
