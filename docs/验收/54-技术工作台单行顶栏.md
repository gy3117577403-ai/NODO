# 54 · 技术工作台单行顶栏

2026-11-20 在本机开发库 `nodo_dev` 用技术岗位会话验证。按批注把柜体选择、出图、视图切换和版本工具放进应用顶栏。打开工作台时，工具栏占用原「技术工作台 / 柜体设计」的位置。从柜体选择器可以查看交接版和台数。左栏直接进入「规格 / 材料 / 附件 / 孔位」。计算异常通过图标提示。

## 实测

- 在 1651 × 871 和 1173 × 871 下，设计和历史阅图都使用同一条 46 px 高的应用顶栏，控件为单行且避开消息、活动和用户区。设计首屏的模型视口从 y=54 px 开始。与上一版同尺寸、同一张 AE-101 V06 总装图对比，图纸画布高度从约 690 px 增到 752 px。两种尺寸下收起目录均可增加图纸可视宽度。
- 在 820 px 和 412 px 宽度下核对控件留在顶栏内，且下载菜单可打开和关闭。
- 实测 AE-101 与 AE-202 切换、二维和三维切换、双门右门定位、设计栏拖宽与收起。取消切柜或取消跳转到「讨论」会保留草稿。确认离开后，「讨论」显示自己的导航，再返回工作台时恢复柜体设计工具栏。
- 通过「一键出图」提交柜宽为 0 的临时输入，工作台显示服务端的柜宽范围提示。出图入口测试在参数校验处结束，下载和阅图使用已有归档。
- AE-303 V02 的门板图放大、平移和同版本三维切换通过，9 项实际下载件与归档摘要一致。AE-101 V05 → V06 → V05 的图纸和三维批次核对通过。
