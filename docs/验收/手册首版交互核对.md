| 路径 | 结果 |

| 管理员配置页 | 从设置用户列表打开采购经办的「个人权限」，核对五项开关、生效值及来源。修改开关的专题实测沿用[采购权限验收](采购协作权限验收.md)。 |

## 发现的交互问题

| 问题 | 实测表现 | 当前走法与后续核对 |
|---|---|---|
| 明细末格按 Tab 后保存会失败 | 编辑采购明细的最后一格单价后按 Tab，会出现另一条空白明细。保留空行点「手动保存」弹出通用错误，技术详情为 `Expected singleton: uom.uom()`。改用鼠标离开明细后保存成功，也复核了删除图标可去掉尚未保存的末尾空白行。[报错界面](27-手册-06-空白明细保存报错.png) | 首版手册使用鼠标离开明细的走法。后续 UI 修复时，应验证末尾空行不会阻断保存，漏填实际物料时指明具体明细。 |
| 保存入口只有图标 | 草稿修改后，表单顶部出现云朵上箭头，按钮可读名称为「手动保存」，按钮本身无文字，紧邻「放弃所有更改」。[保存入口](27-手册-04-草稿保存入口.png) | 文档明确图标和位置。后续核对首次录单时是否需要更明显的保存提示。 |
| 技术分派后没有自动生成待办 | 采购保存负责技术人员后，技术账号刷新能在列表打开 P00004。该单上技术人员的待办数量为零。[核对完成](27-手册-05-技术核对完成.png) | 采购分派后把单号告知技术。后续可评审分派时是否生成站内待办，以及重新分派后的归属。 |
| 公告提示对发言范围表述过窄 | 普通员工看到「本频道仅管理员可发言」。批准角色在同一频道有输入框，符合当前发言配置。[普通员工提示](27-手册-03a-普通员工公告提示.png) · [批准角色输入框](27-手册-03b-批准角色公告输入框.png) | 员工手册解释按频道发言权限开放。后续改文案时，用两种账号对照验证提示与权限，例如「本频道仅获授权的成员可发言」。 |

## 配置差异

开发库可查到「全员通知」「销售报价」「管理员」，本轮未查到「生产协调」。该项是本库的频道配置差异。新环境仍按[频道初始化配置](../../addons/nodo_base/data/discuss_channels.xml)和[验收清单](聊天功能验收清单.md)复核。

## UI 改动时的同步项

1. 从[功能盘点](../手册/功能盘点.md)找到受影响的员工步骤、管理员说明和开发页。
2. 在同一提交更新界面文字、点击步骤、必要截图和此处的对应问题。保留复现方法，标记修复后的实际结果。
3. 用对应的匿名岗位重走发生变化的步骤。只有验证过的操作写入该岗位正式教程。
