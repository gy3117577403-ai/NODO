# 添加成员验收

2026-11-18 · 本机 `nodo_dev` · Chrome 桌面 1440 × 900。使用虚构档案。

| 路径 | 结果 |
| --- | --- |
| 管理员进入「员工 → 管理 → 添加成员」 | 打开单列表单，焦点在姓名，选择部门后列出该部门岗位。选择「全部」时部门留空，已选可用部门时默认带入。 |
| 保存并进入名单 | 「乔予桐」保存后直接进入当前名单，人数从 6 增至 7，新行高亮并显示「待复核」「未开通」。重新进入名单仍可查到。 |
| 重复人员编号 | 使用相同编号的小写形式时被拒绝。姓名、编号和部门保持填写状态。「查看已有档案」打开原记录。 |
| 新成员在当前部门筛选范围外 | 添加「岑雨禾」时原筛选保持生效。点击成功提示中的「查看成员」进入新档案。 |
| 员工详情单独开通账号 | 员工详情的「设置」页可打开独立的账号表单，登录名由管理员填写。关闭表单后员工仍显示「未开通」。 |
| 普通岗位 | 用销售岗位打开员工目录，看不到管理员添加入口。服务端测试覆盖人事人员权限、跨公司或跨部门选择和旧邀请动作。 |

从 [Arc UI 参考](https://uiarc.dev/components/blocks/team-members#preview) 对照首轮截图后，工号由独立宽列移到姓名下方，状态改用浅色标签。NODO 的保存反馈落在新成员行上，人员编号、部门和档案状态来自实际保存的记录。
