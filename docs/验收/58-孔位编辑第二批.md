# 技术工作台孔位编辑第二批

2026-11-20 在本机开发库 `nodo_dev` 使用技术岗位账号验收。现有「孔位」编辑器提供撤销、重做、坐标基准、单轴居中和复制孔。顶栏「三维」「二维」显示同一份草稿，三维中的轮廓预览在保存计算后才成为实体开孔。本批从孔位表单编辑，三维直接点孔和拖孔属于第一批。

## 实测记录

| 样例 | 结果 |
| --- | --- |
| AE-101 单门，门板 415 × 334 mm | H1 原坐标为 U95、V110 mm。切换基准保留原孔位置。复制时原位置被拦截。用 U 终边 279.75 mm 和 V 中心线 −32.25 mm 输入，确认后 H2 的标准坐标为 U135.25、V134.75 mm |
| AE-101 草稿操作 | U/V 居中分别只移动本轴。连续修改一个输入框可一次撤销。实测确认复制、修改、移除的撤销与重做，确认复制时保留三维视图。切到二维读取同一个孔号和坐标 |
| AE-202 双门 | 右门 H1 的 U135 mm 对应终边 370 mm。右门单轴居中后撤销，恢复 370 mm。切换柜体后重新开始该柜的孔位历史 |
| 规格匹配和写入 | 柜宽改变时需要先预览对应规格。样例规格、编辑号和已保存批次回读一致。服务端拦截同一板面的同型、同尺寸、同中心孔，允许双门不同板面使用相同坐标 |

服务端模块测试 13 项通过。另实测 AE-101 门板和 AE-202 右门板三维选面，两组 U/V 与独立投影一致。出图以现有版本验收为准，本次浏览器使用草稿预览。
