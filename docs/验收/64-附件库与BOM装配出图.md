# 64 · 附件库与 BOM 装配出图

2026-11-21 在本机开发库查看独立附件库。用一次性验收库的技术账号实测 BOM、装配及出图。AE-303 使用交接版 2 的同一份 BOM，历史 V02 通过独立归档会话读取原成果。开发库工作台保留 AE-101、AE-202 两个基础柜。

## 附件和装配

| 样例 | 实测结果 |
| --- | --- |
| 独立附件库 | 7 个型号版本，其中 5 个可用于装配，2 个待工程核对。按型号搜索、按状态筛选，加载 T5-55 与待核对角码的三维模型并查看安装规则。 |
| AE-202 双门 | T5-55 在右门板通过预览校核，确认后使用同一份模型。单门方锁 AE-SQ35 显示「柜型不符」，待工程核对的角码也无法选用。 |
| AE-303 交接版 2 | 四行每台各 1 件或 1 套。AE-SQ35 方锁在门板，T5-55 五孔连接板在安装板，EX-COVER 防尘罩在顶板，EX-BASE 焊接底座在底板。预览通过后确认，工作台沿用该三维并提交出图。 |
| AE-303 历史 V02 | 门板展开 SVG、DWG、整包及「本版本三维」逐个与原归档的 SHA-256 比较。三维参数标记 V02。 |

## AE-303 出图回读

同一交接版在验收库生成新批次 V01。浏览器下载了整套图包和 6 个单件文件，摘要逐项等于计算成果。出图结束后重新核对原 V02 的门板 DWG、归档三维和整包，三个摘要与浏览器读取时一致。

| 验证项 | 实测结果 |
| --- | --- |
| 整柜 STEP | 27 个有效具名实体。四种五金分别对应 1、1、5、5 个组成件，安装面、实体包络和定位与图纸一致。 |
| DWG 与切割 DXF | 用 ODA 回读 29 张 DWG，核对原生几何、总装六视图、安装板孔和明细。12 份切割 DXF 与对应 DWG 的 CUT 层逐图元一致。 |
| 门板方孔 | 展开仅有外框和一个 21.2 × 21.2 mm 的方孔。中心在展开 X375.32、Y178.60 mm，重合刀线 0 条。STEP 中对门板沿厚度取三处截面，确认锁颈穿过原孔。 |
| 零件明细 | CSV 27 行与两页 DWG 明细逐项一致。第一页 24 行，第二页 3 行。安装板、顶板和底板分别核对 5、4、4 个安装孔及对应五金实体。 |

新出图批次状态为「待工艺校核」。采购方锁公差及实物工艺待核项沿用[原工程验收](51-AE-303一键出图.md)。

## 复验

使用本机 CAD 工作者、ODA 转换器及可解析 Playwright 的 Node 环境。16 项 `nodo_draw` 测试通过。浏览器验收复用开发机私有归档索引与附件网格，验收库由测试脚本创建及回收。独立回读使用浏览器实际下载的文件和同批次转换前的 DXF。

```powershell
.\scripts\nodo.ps1 test nodo_draw -DrawBrowser
$evidence = Resolve-Path '.nodo-draw/output/playwright/accessory-library'
$run = (Get-Content -LiteralPath (Join-Path $evidence 'new-run-path.txt') -Raw -Encoding utf8).Trim()
uv tool run --offline --no-config --managed-python --python 3.13 --from cadgen==0.7.26 python -X utf8 scripts/draw/verify_ae303.py (Join-Path $evidence '下载') $run
```
