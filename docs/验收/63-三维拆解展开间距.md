# 三维拆解展开间距

2026-11-20 在本机 `nodo_dev` 验收。AE-202 原来的 100% 视角仍有门板、围板和安装板重叠。新版拉开主要板件，点击「完全展开」或松开滑杆后，视口按各可见件自动取景。

| 样例 | 实测结果 |
| --- | --- |
| AE-101 单开门基础柜 | 门板、围板、顶板、底板和安装板为 5 组可见轮廓。1655 × 881 浏览器视口中，主要轮廓离画布边缘最近 89 px。滑杆到 100% 与点「完全展开」的取景一致。验证开门拆解、旋转和缩放，收拢后保留开门姿态。 |
| AE-202 双开门基础柜 | 左右门、围板、顶板、底板和安装板为 6 组可见轮廓，离画布边缘最近 44 px。直接在模型上点中六组板件，零件栏同步高亮。安装板显隐和定位正常，切入「三维开孔」收拢并选中安装板。另在右侧浏览器现有尺寸确认六组完整可见。 |
| AE-303 V02、AE-101 V05 和 V06 | 隔离浏览器会话读取原始归档网格，各批次 SHA-256 核对一致。AE-303 装配及归档视图中，方锁、连接板、顶罩和底座跟随所在板件。 |

开孔回归覆盖两款基础柜。单门和双门均能在可见板面间点选切换，原图孔保护、孔位草稿恢复和双门撤销重做通过。本轮仅验证拆解与开孔交互，整套 CAD 出图沿用原验收记录。
