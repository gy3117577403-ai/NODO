# 55 · 柜型切换与草稿预览

2026-11-20 在本机开发库 `nodo_dev` 用技术岗位账号验证。此前柜型按钮只修改草稿，视口继续显示上次计算的网格。现在柜型切换会自动发起 CAD 草稿预览。计算期间视口显示状态，完成后显示实际柜型和尺寸。已保存设计和出图版本使用各自的记录。

## 实测

- 使用 AE-101 原有的宽 420、高 340、深 235 mm。点「双开门」，首屏进入计算状态，随后显示有中缝的两扇门。实际网格包含 8 个板面，有独立、有效的右门网格，两扇门均可打开。切到「二维」可选择右门板。
- 本机首个双门草稿任务从交给计算服务到完成约 11.18 秒，同一参数复用时，从点选到浏览器显示模型约 0.47 秒。具体耗时受柜体和附件计算量影响。
- 切回「单开门」后即显示原有单门网格，二维回到 7 个板面。刻意延迟双门网格请求并切回单门，页面继续显示单门。以柜宽 0 提交预览时，显示服务端尺寸提示并收起旧模型。
- 双门草稿打开期间，AE-101 V06 的图纸及本版本三维可按批次查看。返回设计视图恢复双门草稿。前后对比保存规格、编辑号及公开批次列表，均一致。
- 模块测试覆盖同参数复用、任务归属权限、保存时使用正式预览批次及旧版数据读取。10 项测试全部通过。
