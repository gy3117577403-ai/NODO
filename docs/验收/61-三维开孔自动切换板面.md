# 三维开孔自动切换板面

2026-11-20 在本机 `nodo_dev` 使用技术岗位账号验收。旧版拾取一直使用上次选中的加工面，复现时点完右侧板再点顶板，左侧仍显示右侧板。新版每次点击都在当前视角重新检测可见加工面，切换后同步更新板面高亮和左侧孔位编辑区。

| 样例 | 实测结果 |
| --- | --- |
| AE-101 单门 | 在同一个三维视口依次点右侧板、顶板，旋转柜体后点后板。返回右侧板时恢复原来的 U69.66 / V194.39 mm 待确认孔位。 |
| AE-101 原图孔 | 从右侧板点门板原有的方口，提示原图开孔或空白区域，对应位置的确认按钮不可用，后板也未被选中。 |
| AE-202 双门 | 直接点右门、左门，撤销及重做各恢复对应门板和坐标。分别恢复两门的待确认孔位，并从左门点右门上已确认的 H1 进入修改。 |

两种柜体仍可直接从三维开孔进入各自的基础原图流程。验收在浏览器草稿中完成，实测前后的已保存设计和历史批次一致。本轮核对原图复用和孔位编辑，生成整套工程文件沿用既有验收记录。
