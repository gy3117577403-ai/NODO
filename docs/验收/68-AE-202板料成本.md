# 68 · 成本库与 AE-202 板料成本

2026-11-23 在本机开发库用核算、技术两个岗位核对。标准 AE-202 宽 1000、深 300、高 700 mm。成本库中 1.5 mm 冷轧板、2.0 mm 冷轧板、2.5 mm 镀锌板均采用 5 元/kg 的测试价，价格依据为「AE-202 样柜试算」。

面积取展开外轮廓，开孔计入，密度按 7.85 g/cm³。七行的金额都取自各行未舍入的用量，包含每台件数。整柜金额按各行未舍入金额相加后取两位小数。左门板、右门板及门内加强件沿用「展开待校核」状态。

## 核对过程

| 操作 | 实际结果 |
| --- | --- |
| 核算员从侧栏打开「成本库 → 板料成本」 | 可查到样柜使用的三条价格，价格性质均为「测试价」。 |
| 技术员同时打开 AE-202「材料」与「零件 → 板料用量」 | 材料分组显示当前元/kg 单价，零件页显示七行成本、整柜总额、右门三维高亮及对应展开图。 |
| 核算员把冷轧板 2.0 mm 从 5 改为 6 元/kg | 已打开的材料页和用量表自动更新，两扇门的单价同步变为 6 元/kg，整柜变为 241.29 元。围板金额仍为 66.840 元。 |
| 临时为该价格指定一个模型未采用的牌号 | 两扇门显示「待补价」，整柜显示「2 种待补价」。其余五种板件仍可看各自的金额和用量。 |
| 恢复原规格并把价格改回 5 元/kg | 当前页和重新打开的 AE-202 用量表均显示 229.43 元。价格更新期间，用量页没有请求重新计算三维或重新展开，右门的展开文件地址相同。 |
| 「材料」中给门板选用库内 2.5 mm 镀锌板，再选未登记的不锈钢规格 | 库内规格一次带入板材和板厚，未登记规格提示待补价。此次选料核对使用页面草稿，前后回读的设计编辑号、参数和出图版本一致。 |
