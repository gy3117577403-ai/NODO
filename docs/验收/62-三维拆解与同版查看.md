# 三维拆解与同版查看

2026-11-20 在本机 `nodo_dev` 使用技术岗位会话验收，视口使用京能 0.57.3 的拆解变换。右下角「拆解」打开 0%～100% 滑杆，可一键收拢或展开。双门柜按柜体尺寸补足左右门板、顶板、底板和安装板的显示位移。

| 样例 | 实测结果 |
| --- | --- |
| AE-101 单开门基础柜 | 滑杆和端点依次到达 0%、50%、100%、0%。全程使用同一画布。拆解时可以旋转、缩放，收拢后恢复开门姿态。右侧板放置直径 22 mm 的待确认孔位，拆解到 50% 后切回三维开孔，板面、U/V 和直径均恢复。再点「三维」恢复 50%。 |
| AE-202 双开门基础柜 | 100% 时左右门板分别向两侧分开，可在模型上逐个点中左门、右门和安装板，左侧零件栏同步高亮。定位、隐藏安装板和全部显示通过。切入三维开孔时收拢并带入安装板。 |
| AE-303 V02 五金装配柜 | 装配视图与「本版本三维」都能拆解。AE-SQ35 方锁随门板，T5-55 连接板随安装板，EX-COVER 顶罩随顶板，EX-BASE 底座随底板。归档视口收到的网格与 V02 原文件的 SHA-256 一致。 |
| AE-101 V06、V05 历史图纸 | 分别打开「本版本三维」，每次从 0% 开始，可展开至 100% 并返回图纸。两次读取的网格各自与归档原文件的 SHA-256 一致。 |

两种基础柜使用当前开发库记录。AE-303 V02 和 AE-101 的旧版本使用隔离浏览器会话与既有归档 CAD 文件。拆解操作期间未触发预览计算或设计保存请求，验收前后的基础柜清单、参数、编辑号和出图版本一致。另复测三维开孔换面、原图孔保护及双门孔位撤销和重做。整套工程文件沿用原出图验收。
