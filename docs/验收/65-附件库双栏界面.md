# 65 · 附件库双栏界面

2026-11-21 更新本机开发库的独立附件库和 BOM 选型弹窗。前后截图使用一次性验收库的技术账号，附件库选中 T5-55，选型弹窗在 AE-202 第 1 行选中 AE-SQ35。

## 验收项目

| 项目 | 实测结果 |
| --- | --- |
| 双栏布局 | 1173 × 871 与 1655 × 881 下，搜索、分类、状态同行。独立附件库和弹窗的七条型号均能在首屏看完。 |
| 浏览与筛选 | 名称搜索、无结果、分类与状态组合筛选和待核对型号预览正常。缩短窗口触发列表滚动后，工具栏和三维画布位置保持一致。 |
| T5-55 默认取景 | 1173 × 871 下，模型占画布高度从 44.7% 提高到 72.4%。1655 × 881 下从 44.6% 提高到 72.4%。新版最窄留边分别为 80 px、81 px。 |
| 三维与规则 | T5-55 可拖动旋转、滚轮缩放和复位。展开规则同时保留当前三维，板厚范围、每台上限和模型来源可见。 |
| AE-202 选型 | 右门板可用的 T5-55 排在首行，单门方锁直接标记「柜型不符」，待核对角码可预览且选用禁用。其他可用板面通过「需调整板面」标记。 |
| BOM 草稿 | 浏览候选再关闭，原型号和右门板保持。点「使用此型号」更新当前行草稿，服务器设计参数和编辑号保持原值。 |
