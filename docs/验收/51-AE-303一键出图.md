## 出图适配与复验

V01 的安装板 STEP 与正视轮廓尺寸正确。绘图阶段为五个安装孔的孔位表上移正视图，投影阶段沿用无孔布局，图纸模型空间内出现 **32.7947 mm** 的位置差，旧版校验阻止整包发布。NODO 适配层按旧版有孔布局在成图前平移安装板投影及虚线层。V02 的正视外廓为 **365×305 mm**，五孔与孔位引线一起通过原版往返校验。旧京能模板和桌面程序作为只读依据。

复验命令接收浏览器下载目录和同批计算目录。计算目录中的转换前 DXF 作为 ODA 回读比较基准。

```powershell
uv tool run --offline --no-config --managed-python --python 3.13 --from cadgen==0.7.26 python -X utf8 scripts/draw/verify_ae303.py "<V02 下载目录>" "<同批次 run-* 目录>"
```
