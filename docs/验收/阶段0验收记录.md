## 过程中发现并修复的问题

| 问题 | 修复 |
|---|---|
| 打印 PDF 时 wkhtmltopdf 回连宿主机地址 127.0.0.1:8079，容器内连不上，单据会丢失样式 | 系统参数 `report.url` 设为容器内地址 `http://localhost:8069`，已写入 `scripts/odoo/setup_dev_db.py` |
| 用 shell 生成的报价单销售员是系统机器人 | 验收脚本指定测试管理员为销售员 |

## 未验证或已知问题

- 打印件抬头显示上游的「Your logo」占位图：开发库公司没有上传 logo。试点时上传本公司 logo。
- 2026-11-16 起，开发库公司名改为「NODO」（用户要求页面按成品呈现，不出现「测试」「示范」等字样）。
