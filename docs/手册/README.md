# NODO 使用与维护手册

首版 · 2026-11-17 核对 · 适用 NODO 开发库，基础版本 Odoo 20.0-20261112。

## 员工从这里开始

| 你要做的事 | 阅读入口 |
|---|---|
| 第一次登录、找应用、和同事聊天、开通知 | [全员入门与讨论](员工/全员入门与讨论.md) |
| 采购助理录草稿、采购或采购经理分派和下单 | [采购与技术协作](员工/采购与技术协作.md) |
| 技术人员查负责的单据、核对规格 | [采购与技术协作的技术核对](员工/采购与技术协作.md#技术人员核对规格) |
| 确认所在部门的功能有没有可用教程 | [功能盘点](功能盘点.md) |

采购部按采购助理、采购、采购经理三个岗位找步骤。技术部按被分派的采购单核对。生产计划部下的仓库和车间随各自流程上线补充操作页，首版可先用全员入门。

## 手册维护

- 修改入口、按钮、字段、状态或权限时，从[功能盘点](功能盘点.md)找到受影响的教程。在同一提交更新步骤、截图和相关开发说明，再用对应岗位走一遍受影响路径。
- 界面问题先写清触发动作、结果和临时走法。UI 修好并复验后，在同一提交更新交互记录和相关手册，移除已经过时的临时走法。
- 新页注明适用版本和核对日期。培训和截图使用匿名账号及虚构单据。账号发放走内部流程。
